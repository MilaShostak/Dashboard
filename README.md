# Employee & Project Dashboard

Веб-приложение для учёта сотрудников, проектов и назначений по месяцам (снимки данных), с расчётом выручки, затрат и прибыли. Задание: [RSSchool outsource-dashboard](https://github.com/rolling-scopes-school/tasks/tree/master/tasks/outsource-dashboard).

## Возможности

- Отдельные данные для каждого месяца (`YYYY-M` в `localStorage`, ключ `monthlyData`)
- Таблицы проектов и сотрудников: сортировка, фильтры, чипы, итоговый Estimated Income
- CRUD сотрудников и проектов, назначения с capacity 0–1.5 и fit 0–1, календарь отпусков
- Копирование месяца (Seed Data) с обнулением отпусков у копии
- Всплывающие окна: сотрудники проекта, назначения сотрудника, подтверждение снятия с проекта

## Технологии

- HTML, CSS, ванильный JavaScript (ES modules)
- Без фреймворков и jQuery, по требованиям задания

## Запуск

Локально откройте `index.html` в браузере или поднимите статический сервер в корне репозитория, например:

```bash
npx serve .
```

Для GitHub Pages укажите корень сайта на каталог с `index.html`.

## Особенности реализации

- Формулы эффективной занятости, выручки и затрат соответствуют спецификации в README задания
- Стартовые демо-данные создаются только если в `localStorage` ещё нет ни одного месяца с данными
- Фильтры и сортировка хранятся только в памяти страницы; в `localStorage` пишутся сотрудники и проекты
